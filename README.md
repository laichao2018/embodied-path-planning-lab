# NAV STUDIO - 路径规划工作台

一个用于算法对比与调试的全屏交互式路径规划工作台，把障碍建模、搜索前沿、路径生成和机器人执行放进同一张可视化地图。

## 主要功能

- 有限栅格区域、边界障碍、静态障碍和持续运动的动态障碍
- 默认地图为 120 × 100；可输入并应用 32–240 列、20–200 行，大地图会自动缩放渲染分辨率，保持交互流畅
- 白色底图与红色膨胀 / 代价图层，代价随离障碍距离增加逐渐变浅
- 动态障碍支持规则移动、随机平滑移动，并可直接在地图上自行放置
- 在地图上交互设置起点与终点，并支持一键重置
- 同时运行 A*、Dijkstra、RRT 和 RRT*，以蓝、黄、红、紫四种高区分度颜色显示
- 算法使用下拉多选；每个已勾选算法都会在下方同步展示自己的实时搜索状态，取消勾选即隐藏
- 全局路径生成后由 DWA 局部规划自动接管：实时采样速度/角速度窗口、显示候选轨迹，并绕开静态、动态和膨胀障碍
- 静态障碍支持拖动移动；在地图空白处或障碍物上右键，可添加、调整尺寸或清除静态障碍
- 动态展示 `GENERATE` 与 `PICK`：新节点、当前扩展节点、搜索树和最终路径
- 搜索完成后，机器人沿优先路径执行；动态障碍持续更新
- 可调障碍膨胀半径、动画速度和参与对比的算法

## 算法说明

- **A***：使用 `g(n) + h(n)` 进行目标导向搜索。
- **Dijkstra**：使用累计代价 `g(n)` 进行等代价扩展。
- **RRT**：通过随机采样、最近邻、Steer、连续边碰撞检测与 parent 回溯生成路径。
- **RRT***：在 RRT 树生长基础上执行邻域最优父节点选择和重连优化，持续降低累计路径代价。
- **DWA 局部规划**：全局路径完成后，滚动评估短时预测轨迹，从安全候选中选择速度和角速度控制量；动态障碍进入膨胀区时，小车会减速、转向或等待安全窗口。
- **动态环境**：动态障碍与局部代价地图持续更新，用于观察路径规划过程中的环境变化。

## 零依赖启动（推荐）

```bash
cd /Users/laichao/workspace/embodied-path-planning-lab
sh start.sh
```

`start.sh` 会直接用系统浏览器打开离线 Demo。运行过程不需要联网，也不需要安装 Node.js、npm、Python 或任何第三方软件包。

克隆 GitHub 项目后也可以直接启动：

```bash
git clone https://github.com/laichao2018/embodied-path-planning-lab.git
cd embodied-path-planning-lab
sh start.sh
```

离线程序位于 `standalone/`，只使用浏览器原生的 HTML、CSS、JavaScript 和 Canvas API。

## 开发模式（可选）

如需修改 React / TypeScript 开发版，再使用 Node.js：

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

自动验证代价地图和四种规划算法：

```bash
npm test
```

一次完成算法测试与生产构建：

```bash
npm run verify
```

## 交互说明

1. 输入地图列数与行数并点击“应用”，或选择“原始 / 膨胀 / 代价”图层观察地图预处理结果。
2. 选择动态障碍的规则或随机移动方式；点击“添加障碍”后，可在地图空白区域连续放置动态障碍。
3. 按住地图中的绿色起点箭头或橙色终点旗帜，将图标拖到目标栅格；障碍区域会自动拒绝放置。
4. 拖动深灰色静态障碍即可移动；右键单击空白处添加静态障碍，或右键单击已有障碍调整宽高、清除它。
5. 在算法下拉框中勾选需要比较的算法；每个已勾选算法的推演数据都会在下方显示。
6. 点击“启动路径规划”。亮环表示当前扩展节点，微光节点或树枝表示本步新生成的候选节点。
7. 全局路径完成后，DWA 自动展示淡绿色候选轨迹、亮绿色选中局部轨迹与深绿色实际行驶轨迹，并对实时障碍绕行。
8. 拖动地图下方的 `REPLAY` 时间轴，可前后查看任意阶段的搜索推演过程。
