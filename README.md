# PATH LAB 06 - 具身智能路径规划演示

一个用于教学与算法对比的交互式路径规划 Demo。项目结合课程中 A* / Dijkstra、RRT、DWA 与 TEB 的核心思想，把障碍建模、搜索前沿、路径生成和机器人执行放进同一张可视化地图。

## 主要功能

- 有限栅格区域、边界障碍、静态障碍和持续运动的动态障碍
- 原始地图、障碍膨胀地图、渐变代价地图三层切换
- 在地图上交互设置起点与终点，并支持一键重置
- 同时运行 A*、Dijkstra 和 RRT，以青、橙、玫红三种颜色区分
- 动态展示 `GENERATE` 与 `PICK`：新节点、当前扩展节点、搜索树和最终路径
- 搜索完成后，机器人沿优先路径执行；动态障碍持续更新
- 可调障碍膨胀半径、动画速度和参与对比的算法

## 课程概念映射

- **A* / Dijkstra**：统一 Open Set / Closed Set 搜索框架，区别在于优先级 `g(n)` 与 `g(n) + h(n)`。
- **RRT**：随机采样、最近邻、Steer、连续边碰撞检测与 parent 回溯。
- **DWA**：动态障碍与局部代价地图持续更新，强调“生成 - 预测 - 筛选 - 评分 - 执行”的滚动闭环。
- **TEB**：作为工程延伸，强调路径形状与时间分配的联合优化；当前 Demo 聚焦全局搜索与局部反应的可视化。

## 本地运行

```bash
npm install
npm run dev
```

打开终端提示的本地地址。生产构建：

```bash
npm run build
```

自动验证代价地图和三种规划算法：

```bash
npm test
```

一次完成算法测试与生产构建：

```bash
npm run verify
```

## 交互说明

1. 选择“原始 / 膨胀 / 代价”图层观察地图预处理结果。
2. 单击地图依次设置起点 `S` 与终点 `G`，或用左侧按钮指定当前要设置的点。
3. 勾选需要比较的算法，调整膨胀半径与推演速度。
4. 点击“启动路径规划”。亮环表示当前 `PICK` 节点，微光节点或树枝表示 `GENERATE`。
